🏥 AI Medical Intelligence Platform

Project Overview

This project is an AI-powered healthcare application developed using Flask, TensorFlow, and Machine Learning. It provides medicine recommendations based on similarity and predicts chest diseases from X-ray images using a CNN model.

Features

  • 💊 Medicine Recommendation System
  • 🩻 Chest X-ray Disease Detection
  • 🔥 Grad-CAM Visualization
  • 🗃️ Prediction History
  • 📈 Model Accuracy Display
  • ⏰ Prediction Time

Technologies Used

  • Python
  • Flask
  • TensorFlow / Keras
  • OpenCV
  • SQLite
  • HTML
  • CSS
