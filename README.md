# 🩺 Advanced AI Medical Intelligence Platform

> An AI-powered healthcare application that analyzes chest X-ray images using Deep Learning, provides explainable predictions with Grad-CAM, and generates AI-assisted medical reports using Google Gemini.

## 🎯 Project Overview

The Advanced AI Medical Intelligence Platform combines Deep Learning,
Computer Vision, Explainable AI, and Generative AI into a single
healthcare-focused application.

The system analyzes chest X-ray images and predicts whether the image
indicates pneumonia. It uses Grad-CAM to provide visual explanations
for the model's prediction and Google Gemini to generate AI-assisted
medical reports.

The project achieved **89.74% accuracy** for pneumonia detection.

> ⚠️ This project is intended for educational and research purposes
> and should not be used as a substitute for professional medical
> diagnosis.

- 🩻 Chest X-ray disease detection
- 🧠 CNN-based Deep Learning model
